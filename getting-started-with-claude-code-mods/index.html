mod 是一个跑在你 Claude Code session 里的小 JavaScript 或 TypeScript 文件。它可以观察正在发生什么、改变 Claude Code 的行为，或者画自己的 UI——在终端里或桌面 App 里。想试用一个，不用先学 API。跑 claude，然后描述你想要的 mod。它问起时允许 hot reload，回合结束 mod 就出现了。

Claude Code 本来就能让你改很多行为：settings、permission rules、slash commands、skills 和 status line。mod 走得更远：它能改写或替换 Claude Code 做的事，还能画自定义 UI。底层看，mod 是装在 plugin 里的 hook，session 里每个事件发生时它都看得到。

这让 mod 成为把 Claude Code 调成你工作方式的手段。加一个你总在看的数据读数，给让你心里没底的命令前加一道守卫，或者搭一个按你习惯读改动的 review 视图。

这份指南从一个空文件夹做出一个 mod：Token Weather，画在 prompt 上方的 context window 实时天气预报。大约 80 行。之后逛两个更大的 mod——Blast Radius 和 Replay Theater——看 API 还能干什么。三个的完整代码在 anthropics/claude-code-playground。

Claude Code 2.1.287 或更新。mod 默认开启，没什么要打开的。API 在不同版本间会变。每次 Claude Code 加载一个 mod，都会把你的构建对应的类型声明写进该 mod 的 .claude-plugin/types/ 文件夹，它们才是你那个版本的权威。

mod 怎么工作

mod 是一个 Claude Code plugin，行为写在一个 JavaScript 或 TypeScript module 里：

  • 文件夹是个普通 plugin，带 .claude-plugin/plugin.json manifest。
  • hooks/hooks.json 在 modules 下指名一个 module。
  • module 导出 register(on, options)。在里面，on(event, matcher?, hook) 添加一个 hook。

    • 每个 hook 都是同一个形状：

    hook 串成一条链，像 middleware。你的跑完，next(e) 把事件交给下一个 plugin，链底 Claude Code 做它本来就会做的事。一个 hook 只能干三件事之一：

    hook 串成链
    动作 怎么做 例子 观察 const r = await next(e); /* look */ return r 记录每次文件编辑。每个回合后取一次读数。 改写 return next({ ...e, command: safer }) 改变链上其余部分看到的。 应答 return { deny: "…" } 而不调 next 拒绝一个 tool call。自己提供一条 command 或一个 tool。

    事件覆盖 tool call、提交时的 prompt、回合的开始和结束、session 的启动和结束、slash command，还有 ui.render：界面画出来的每一部分。module 跑在独立的 sandbox 里，没有 DOM 也没有 Node，所以外面的一切都走 $。

    和 settings hook 的区别。settings hook 每个事件跑一条 shell 命令，JSON 走 stdin 和 stdout。mod 加载一次，留在 session 里。它能保存状态、画随事件更新的 UI，还能回调 Claude Code：开 pane、跑进程、注册 slash command，或注册一个模型能调用的 tool。

    Claude Code 自己也在用。Claude Code 的一些自带功能就是按 mod 做的，包括 AGENTS.md 支持和对话旁的 /diff pane。源码带测试，放在公开的 anthropics/claude-code 仓库的 mods/ 下，你可以读团队怎么做。

    Blast Radius：危险命令跑之前，先看它会改什么

    Claude 用 rm -rf、git reset --hard、git clean、force push 或数据库迁移调 Bash 时，Blast Radius 把这次调用拦下来。它算出命令会碰到什么，开一个带 Proceed 和 Cancel 的 pane。按 2，Claude 收到带理由的拒绝。按 1，命令照原样执行。

    它用了三个 hook：Bash 上的 tool.call，Pane 和 AbovePrompt 上的 ui.render。核心就是上面表格里的"应答"动作：

    它教会你的：

  • $.process.run 跑 dry run。报告来自工具自己的命令：git status --porcelain、git clean -n、git log HEAD..origin/main、showmigrations。参数以 argv 数组传入，路径里的东西不会被当 shell 代码执行。
  • 拦住一次调用。hook 每次 dispatch 有 10 秒自己的时间，但花在 $ 调用里等待的时间不算。循环等短 sleep 进程，直到按钮的 onPress 设定决定；next.signal abort 时它放弃（你按了 Esc）。
  • 带热键的按钮。Button({ label: \"Proceed\", hotkey: \"1\", onPress }) 点、Tab 加 Enter、数字键都能操作。
  • 降级到 band。终端够宽时把 pane 停在 transcript 旁边。$.ui.open 回答 isPlaced: false 时，同样的报告画在 prompt 上方：

    • 它是安全网，不是权限系统。它读的是命令文本，$(…)、alias 和调用 rm 的脚本都能绕过它。要硬拦，用 permission rules。

    Replay Theater：逐步回看上上个回合的编辑

    回合运行期间，Replay Theater 记录每次 Edit 和 Write 调用：文件，加上前后的文本。回合结束，prompt 上方出现一个提示。按 r（或输入 /replay），一个 pane 逐个 diff 地走这些编辑，带一条编号步骤和 Prev、Next、Close 按钮。

    它从不拦截或改变任何编辑。它只是观察：

    它教会你的：

  • 成对事件。turn.start 和 turn.complete 把编辑框进一个回合一份回放，e.agentId 让 subagent 的回合不混进分组。
  • 注册 slash command。在 session.start 里 $.command.register，然后在 command.run 上应答它。
  • 读文件。对 Write，$.fs.read 在写入落地前一刻拿到旧内容，diff 才是真的。
  • 摆放是 surface 的事。全屏时 pane 停在右边，80 列时它在 prompt 上方内联打开。mod 两种情况画的是同一棵树。

    • 值得保持的四个习惯

  • 靠 Claude Code 替你写的类型。每次加载你的 mod，Claude Code 把你构建的声明写进该 mod 的 .claude-plugin/types/ 文件夹，你的编辑器和 tsc -p 不用额外步骤就能工作。它们是每个事件、$ 上每个方法、每个元素 props 的参考。
  • props 从 e.props 读。hasSurvey、bodyColumns 这些都在那里，不在 e 本身上。
  • 为 hot reload 做打算。每次保存都会重跑 register 和 session.start，所以数据放 $.state，别放 module 变量。
  • 画不出现时，读日志。跑 claude --debug，找一行说 hook 返回了校验不过的树。

    • 你会 mod 什么？

    这里的三个 mod 各来自一个问题：我的 context 有多满？、这条命令要删什么？、Claude 刚才改了什么？你的问题会不一样，这正是重点。几个可以起步的想法：

  • 从 $.session.usage() 做一个成本或限流表，用 $.ui.status 当 status line
  • 一个 prompt.submit hook，把团队的约定加进每个 prompt
  • 一个 pane 列出这个 session 里 Claude 读过的文件，当它见过什么的实时地图
  • 一个专注计时器，长回合结束时用 $.ui.toast 发个 toast
  • 一个按你的技术栈调好的 tool.call 守卫，比如生产 kubectl context 或 terraform apply

    • 分享你做的

    做了个现在天天用的 mod？发到 X 或 LinkedIn 上，带一段它运行的 GIF 或截图，让别的开发者看看能做到什么。把 plugin 放进一个 marketplace（分享你的 mod）并链接到它，喜欢的人三条命令就能装上。

const readings = { plugin: "token-weather", key: "readings" };

export function register(on) {
  on("session.start", async ($, e, next) => {
    const result = await next(e);
    await takeReading($);
    return result;
  });

  on("turn.complete", async ($, e, next) => {
    const result = await next(e);
    if (!e.agentId) {
      await takeReading($); // main-loop turns only, not subagents
    }
    return result;
  });

  on("ui.render", { component: "AbovePrompt" }, async ($, e, next) => {
    const { value: history = [] } = await $.state.get(readings);
    if (e.props.hasSurvey || history.length === 0) {
      return next(e);
    }
    const { Box, Text } = $.ui.resolve(e);
    return band(Box, Text, history, e.props.bodyColumns);
  });
}

async function takeReading($) {
  const { context } = await $.session.usage();
  if (!context?.window) return;
  const tokens = context.tokens ?? 0;
  const percent = context.percent ?? Math.round((tokens / context.window) * 100);
  const { value: history = [] } = await $.state.get(readings);
  await $.state.set(readings, [...history, { tokens, window: context.window, percent }].slice(-HISTORY));
}

function band(Box, Text, history, columns) {
  const now = history[history.length - 1];
  const f = FORECAST.find((b) => now.percent < b.upTo);
  const parts = [
    Text({ color: f.color, bold: true, children: `${f.icon}  ${f.word}` }),
    Text({ children: `  ${now.percent}% of context` }),
    Text({ dimColor: true, children: `  ${short(now.tokens)} / ${short(now.window)}` }),
  ];
  if (columns >= 60) {
    parts.push(Text({ dimColor: true, children: "   last turns " }));
    parts.push(Text({ color: f.color, children: sparkline(history) }));
    if (history.length > 1) {
      parts.push(Text({ dimColor: true, children: trend(history) }));
    }
  }
  return Box({ flexDirection: "row", paddingX: 1, children: parts });
}

function sparkline(history) {
  const top = Math.max(...history.map((r) => r.tokens), 1);
  return history.map((r) => BARS[Math.floor((r.tokens / top) * (BARS.length - 1))]).join("");
}

function trend(history) {
  const delta = history[history.length - 1].tokens - history[history.length - 2].tokens;
  if (delta === 0) return "  steady";
  return delta > 0 ? `  ▲ +${short(delta)} last turn` : `  ▼ ${short(-delta)} last turn`;
}

function short(n) {
  if (n >= 1_000_000) return `${+(n / 1_000_000).toFixed(1)}M`;
  if (n >= 1_000) return `${+(n / 1_000).toFixed(1)}k`;
  return String(n);
}

    on("tool.call", { tool: "Bash" }, async ($, e, next) => {
  const risk = classify(String(e.command ?? ""));
  if (risk === null) return next(e);                 // everything else runs as normal

  const report = await measure($, risk, await $.session.cwd());  // git status, git clean -n, du, ...
  held = { command: e.command, risk, report, decision: null };
  const opened = await $.ui.open({ id: "blast-radius", title: "Blast Radius", focus: true });
  if (!opened.isPlaced) held.where = "band";         // too narrow for a pane: draw above the prompt

  while (held.decision === null && !next.signal.aborted) {
    await $.process.run(["sleep", "0.25"]);          // time inside $ calls doesn't count against the hook's time limit
  }
  if (held.decision === "proceed") return next(e);   // let it run
  return { deny: `Blast Radius held this command: the user pressed Cancel. It would have: ${report.summary}.` };
});
